# Финконтроль ресторанной группы

Адаптивный лендинг с четырьмя блоками автоматизации и пошаговой лидформой.

## Размещение

GitHub Pages публикует корень ветки `main`. После отправки изменений сайт обновляется автоматически.

## Локальный просмотр

```sh
python3 -m http.server 4173
```

## Форма

Форма готовит текст заявки и открывает WhatsApp-чат `+62 878-6714-3626` (`https://wa.me/6287867143626`). Посетитель отправляет сообщение самостоятельно. Серверного хранения контактов и автоматической отправки ботом нет.

Название «финконтроль» — рабочее. Данные финансовой панели иллюстративные.

Фото интерьера: [Unsplash](https://unsplash.com/photos/1517248135467-4c7edcad34c4), asset photo-1517248135467-4c7edcad34c4.

## Проверка адаптивности

Проверены браузерные размеры 320, 360, 390, 480, 600, 768, 820, 900, 1024 и 1440 px: отсутствие горизонтальной прокрутки, зоны нажатия основных элементов не меньше 44 px, все шаги формы, валидация телефона и сохранение ответов при возврате. Мобильные CTA ведут прямо к вопросу; плавающая кнопка скрывается на первом экране, в форме и при вводе. На телефоне убраны дублирующие мини-диаграммы и фотография перед формой. Проверка в браузере не заменяет проверку клавиатуры и WhatsApp на физических iOS/Android устройствах.

Контакт для обработки лидов: WhatsApp +62 878-6714-3626. Отвечает человек. Автоматические ответы не подключены.

Перед публикацией изменений запустите `python3 prepare-release.py`. Скрипт создаёт файлы JS и CSS с хешем содержимого в имени и обновляет ссылки в `index.html`. Это предотвращает смешивание новой HTML-страницы со старым скриптом из браузерного кеша. Ранее опубликованные файлы в `assets/` сохраняются для открытых старых версий страницы.
