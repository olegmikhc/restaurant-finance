# Финконтроль ресторанной группы

Адаптивный лендинг с четырьмя блоками автоматизации и пошаговой лидформой.

## Размещение

GitHub Pages публикует корень ветки `main`. После отправки изменений сайт обновляется автоматически.

## Локальный просмотр

```sh
python3 -m http.server 4173
```

## Форма

Форма готовит текст заявки и открывает Telegram-чат `@olegmikhb`. Посетитель отправляет сообщение самостоятельно. Серверного хранения контактов и автоматической отправки ботом нет.

Название «финконтроль» — рабочее. Данные финансовой панели иллюстративные.
